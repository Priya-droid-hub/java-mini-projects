# Java Swing To-Do List

A simple Java desktop application for keeping track of daily tasks. Built using Swing to create a graphical interface and AWT for handling user interactions.

## Features

* Add and manage tasks
* Simple, clean graphical interface
* Easy-to-use desktop application

## Tech Stack

Java · Swing · AWT

## Run Locally

Open `Main.java` in your Java IDE and run the `main()` method.
