 # 🐍 Snake Game

A classic Snake Game built using **Java Swing** as a hands-on project to practice Java fundamentals, GUI development, and game logic.

## Features

* Keyboard-controlled snake movement
* Multiple food types and scoring
* Five levels with increasing difficulty
* High-score tracking
* Pause and resume
* Restart functionality
* Collision detection

## Tech Stack

* Java
* Java Swing
* Maven

## Controls

`↑ ↓ ← →` — Move
`Space` — Pause / Resume
`Enter` — Restart

## Run

Open `SnakeGame.java` in IntelliJ IDEA and run the `main()` method.
